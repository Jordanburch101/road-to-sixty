# App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wrap the `rts-sync` engine in a Tauri app that lives in the Mac menu bar and the Windows tray, walks a new player through first-run setup, shows their characters and sync status in look A from the mockups, starts at login, updates itself, and builds for Mac and Windows in CI.

**Architecture:** A new crate `apps/desktop/src-tauri` (`road-to-sixty-app`) owns one `Runner`, which runs `rts_sync::watch::run` on a thread and turns each engine report into a `Status` (plain, tested functions in `status.rs`). Every change to the status goes through a `Notifier`, which updates the tray's menu and emits a `status` event to the window. The window is Vite and React in `apps/desktop/src`, styled from `packages/ui`, the shared look the website will also use. Anything that restarts the sync thread (link, pause, unlink, add a folder) runs on its own thread, so neither the window nor the tray ever waits on an upload.

**Tech Stack:** Tauri 2.12.3 (tray-icon, image-png), tauri-plugin-dialog 2.8.2, -opener 2.7.1, -single-instance 2.5.3, -autostart 2.7.0, -updater 2.13.3, @tauri-apps/cli 2.12.2; Vite 8.3.4, React 19.3.0, Tailwind 4.3.3 (@tailwindcss/vite), @fontsource-variable/geist and geist-mono 5.3.0; the Tauri CLI and the aws CLI (to R2) in GitHub Actions; Rust 1.99.0 (rust-toolchain.toml), Bun 1.4.2.

**Spec:** `docs/superpowers/specs/2026-10-12-sync-and-backup-design.md`, sections "The desktop app" (all four parts), "The website" (Look; the account screens table), "Repo layout", "Testing" (App). The look comes from the mockups Jordan picked on 2026-10-14 (look A with the fog of war background): https://claude.ai/artifact/M1btBtHDuiExpSuHU7Pg8Z, boards "A · First run" and "A · Characters". Their source is quoted where a task needs it.

## Decisions this plan makes (Jordan to confirm before Task 7)

1. **Where downloads live** (Jordan, 2026-10-14). This repo is private, so its GitHub release downloads would need a login. App builds go to a public R2 bucket, `road-to-sixty-downloads`, served at `https://dl.rts.everhold.online` (moving to a `roadtosixty.online` name at release, with the old one kept for older builds). Each version sits under `app/<version>/`. The website links to fixed names, `app/Road-to-Sixty.dmg` and `app/Road-to-Sixty-Setup.exe`. The updater reads `app/latest.json`, which CI writes itself and uploads last, so it never names files that aren't there yet.
2. **The Keychain asks again after each update on the Mac.** The build is only ad-hoc signed, so macOS treats each new build as a different app, and the Keychain asks once per update whether it may read the PC token. "Always Allow" covers that build. The only real fix is a Developer ID ($99 a year). Until then, the download page tells testers to expect it.
3. **Start at login uses a LaunchAgent, not SMAppService.** tauri-plugin-autostart 2.7.0 offers only LaunchAgent or AppleScript. A LaunchAgent shows under System Settings, General, Login Items, "Allow in the Background". On Windows the plugin uses the per-user Run key, as the spec says. The spec is updated to match.
4. **Scope.** The Characters screen shows what this PC and the sync check know: each character's name and realm, whether it is played here, and its sync state. Level, class, time played and which PC need the account API, which is the next plan. So do the PCs tab, character history, restore (with the restore-id fix noted on #1), download-my-data and delete-everything. This plan's window has two tabs, Characters and Account. Account shows the link, the game folders, start at login, updates and Unlink this PC.
5. **The tray menu** is: the status line, Open Road to Sixty, Pause syncing or Resume syncing, Check for updates (or Restart to update), and Quit Road to Sixty. The spec's "Open website" item goes, because the website is download-only. "Link this PC" and "Game folders" live in the window.
6. **Icons** (Jordan, 2026-10-14: use the compass as is). The app icons are made from the 256 px compass without scaling it first. The tray uses the same colour compass at 32 px, not a black-and-white menu bar icon.
7. **Pause lasts until the app quits.** It isn't saved; the app syncs again after a restart.

## Global Constraints

- Subagents use at most `model: "opus"`, never Fable.
- Never commit secrets, personal paths or email addresses. The updater's private key and the downloads bucket's keys live only in GitHub secrets and in `~/.config/road-to-sixty/` (mode 600). Real SavedVariables files never go into the repo or a test: tests use hand-made files with made-up names.
- The app never writes the game's SavedVariables, not even for a restore (spec, "While running").
- A character is named by the `rosterKey` in its saved file, never by the game's folder names (spec, "While running").
- The backend address is built into each app build (`RTS_SERVER` at build time, defaulting to `https://api.rts.everhold.online`), never typed in by the player (spec, "Domains").
- Look A: background `#07060a`, panel `#0c0b10`, lines `#1f1d26` and `#1a1820`, outline `#2a2733`, text `#ece9f2`, muted `#9a95a8`, faint `#6f6a7d`, cream button `#f7f4ee` with ink `#17141d`, accent `#3aa0ff` for the sync dot, the setup tick and the lit fog only, warning `#e5b84a`. Geist and Geist Mono. Class colours from the mockup are not used yet (no class data until the account API).
- Copy is plain English for players, British spelling, no jargon ("Link this PC", "Restart WoW once").
- Code comments follow CLAUDE.md: plain sentences that explain why, only what the code can't say.
- Commit subjects `Desktop: what changed (#1)`; work happens on a feature branch `app-shell`, merged locally into `dev`, never pushed to `main`.
- App releases use `app-v*` tags, so they never start the addon's `v*` release workflow (spec, "Signing and builds").

## Review Focus

1. A pause, unlink or new folder while an upload is in flight: the window and the tray stay responsive, and afterwards exactly one sync thread runs. Task 4 tests starting twice; Task 5's hands-on list covers responsiveness.
2. The server stops accepting the PC token (unlinked from another PC, or the account deleted): the tray says "Not linked" and the window offers linking again, instead of a stale "Synced". Task 3 tests it.
3. A PC with WoW in an unusual place: first run says WoW wasn't found and offers "Add a game folder…". Picking a folder with no game folder that has the addon says so, rather than doing nothing. Task 4 tests it.
4. Closing the window doesn't stop syncing, and opening the app a second time (say, from the Applications folder while it starts at login) shows the window instead of starting a second copy. Task 5's hands-on list covers both.
5. After an update and restart, the PC stays linked and syncing (the token is in the Keychain, the state file is untouched). Task 7's first release is checked by updating 0.1.0 to 0.1.1 on a real Mac.

```ts
// The fog of war background: a grid of faint dots, lit along the roads a
// journey took, like the map uncovering where you've been.

export type Point = [number, number];

// Grid dots start half a step in, so the grid sits centred in the box.
export function fogDots(width: number, height: number, step: number, roads: Point[][]) {
  const lit: Point[] = [], edge: Point[] = [], fog: Point[] = [];
  for (let x = step / 2; x < width; x += step) {
    for (let y = step / 2; y < height; y += step) {
      let near = Infinity;
      for (const road of roads) {
        for (let i = 0; i + 1 < road.length; i++) near = Math.min(near, distance([x, y], road[i]!, road[i + 1]!));
      }
      (near < step * 1.2 ? lit : near < step * 3.2 ? edge : fog).push([x, y]);
    }
  }
  return { lit, edge, fog };
}

function distance([px, py]: Point, [ax, ay]: Point, [bx, by]: Point) {
  const dx = bx - ax, dy = by - ay;
  const t = Math.max(0, Math.min(1, ((px - ax) * dx + (py - ay) * dy) / (dx * dx + dy * dy || 1)));
  return Math.hypot(px - ax - t * dx, py - ay - t * dy);
}
```

```tsx
import { useMemo } from "react";
import { fogDots, type Point } from "./fog";

// Draws the fog grid at a fixed size; the parent clips and fades it.
export function Fog({ width, height, step, roads, marks = [] }: { width: number; height: number; step: number; roads: Point[][]; marks?: Point[] }) {
  const { lit, edge, fog } = useMemo(() => fogDots(width, height, step, roads), [width, height, step, roads]);
  return (
    <svg aria-hidden="true" width={width} height={height} viewBox={`0 0 ${width} ${height}`} className="pointer-events-none absolute left-0 top-0">
      {fog.map(([x, y]) => <circle key={`f${x},${y}`} cx={x} cy={y} r={1.1} fill="rgba(154,149,168,0.16)" />)}
      {edge.map(([x, y]) => <circle key={`e${x},${y}`} cx={x} cy={y} r={1.4} fill="rgba(154,149,168,0.4)" />)}
      {lit.map(([x, y]) => <circle key={`l${x},${y}`} cx={x} cy={y} r={1.8} className="fill-accent" fillOpacity={0.85} />)}
      {marks.map(([x, y]) => (
        <g key={`m${x},${y}`}>
          <circle cx={x} cy={y} r={8} fill="none" className="stroke-accent" strokeOpacity={0.35} />
          <circle cx={x} cy={y} r={3} className="fill-accent" />
        </g>
      ))}
    </svg>
  );
}
```

```ts
import { listen } from "@tauri-apps/api/event";
import { confirm, open } from "@tauri-apps/plugin-dialog";

export type Game = { path: string; name: string; addon: string | null };
export type Character = { key: string; here: boolean; updateAddon: boolean; uploaded: number | null; note: string };
export type Status = {
  linkedTo: string | null;
  games: Game[];
  characters: Character[];
  lastSynced: number | null;
  paused: boolean;
  offline: boolean;
  problems: string[];
  linkCode: string | null;
  line: string;
};

export const getStatus = () => invoke<Status>("status");
export const onStatus = (show: (s: Status) => void) => listen<Status>("status", (e) => show(e.payload));
export const link = () => invoke("link");
export const setPaused = (paused: boolean) => invoke("set_paused", { paused });
export async function unlink() {
  if (await confirm("Syncing stops on this PC. Your journeys stay here and on the server.", { title: "Unlink this PC?", kind: "warning" })) await invoke("unlink");
}

export async function addFolder() {
  const path = await open({ directory: true, title: "Pick your World of Warcraft folder" });
  if (typeof path === "string") await invoke("add_folder", { path });
}
```

```tsx
import { useEffect, useState } from "react";
import { getStatus, onStatus, type Status } from "./api";
import { Account } from "./Account";
import { Characters } from "./Characters";
import { FirstRun } from "./FirstRun";

export function App() {
  const [status, setStatus] = useState<Status | null>(null);
  // Linking finishes on step 2; step 3 (restart WoW) stays up until Done.
  const [restartStep, setRestartStep] = useState(false);
  const [tab, setTab] = useState<"characters" | "account">("characters");

  useEffect(() => {
    getStatus().then(setStatus);
    const stop = onStatus(setStatus);
    return () => void stop.then((unlisten) => unlisten());
  }, []);
  useEffect(() => {
    if (status?.linkCode) setRestartStep(true);
  }, [status?.linkCode]);

  if (!status) return null;
  if (!status.linkedTo || restartStep) return <FirstRun status={status} onDone={() => setRestartStep(false)} />;
  return tab === "characters"
    ? <Characters status={status} onTab={setTab} />
    : <Account status={status} onTab={setTab} />;
}
```

```rust
//! What the app shows: the line in the tray menu and the window's state,
//! worked out from the sync engine's reports. Plain functions, so the
//! wording is tested without a window.

use rts_sync::api::ApiError;
use rts_sync::sync::Report;
use serde::Serialize;

#[derive(Debug, Clone, Default, PartialEq, Eq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct Status {
    /// The BattleTag this PC is linked to. None before linking, and after
    /// the server stops accepting the token.
    pub linked_to: Option<String>,
    pub games: Vec<Game>,
    pub characters: Vec<Character>,
    /// Unix seconds of the last pass that reached the server.
    pub last_synced: Option<u64>,
    pub paused: bool,
    /// The last pass couldn't reach the server; the engine tries again.
    pub offline: bool,
    pub problems: Vec<String>,
    /// While linking, the code the link page shows, to compare.
    pub link_code: Option<String>,
    /// The tray's status line, also shown in the window.
    pub line: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct Game {
    pub path: String,
    pub name: String,
    pub addon: Option<String>,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct Character {
    /// `Name-Realm`, from the saved file's rosterKey or the server.
    pub key: String,
    /// Its saved file is on this PC.
    pub here: bool,
    pub update_addon: bool,
    /// When this run of the app last uploaded it, in Unix seconds.
    pub uploaded: Option<u64>,
    /// The line under the name.
    pub note: String,
}

pub fn ago(secs: u64) -> String {
    match secs {
        0..60 => "just now".into(),
        60..3600 => format!("{} min ago", secs / 60),
        3600..86_400 => format!("{} h ago", secs / 3600),
        86_400..172_800 => "yesterday".into(),
        _ => format!("{} days ago", secs / 86_400),
    }
}

/// Folds one engine report into the status. `local` is every character
/// with a saved file on this PC.
pub fn apply(status: &mut Status, result: &Result<Report, ApiError>, local: &[String], now: u64) {
    match result {
        Ok(report) => {
            status.offline = false;
            status.last_synced = Some(now);
            status.problems = report.problems.clone();
            let mut keys: Vec<String> = report.characters.iter().chain(local).cloned().collect();
            keys.sort();
            keys.dedup();
            let before = std::mem::take(&mut status.characters);
            status.characters = keys
                .into_iter()
                .map(|key| Character {
                    here: local.contains(&key),
                    update_addon: report.update_addon.contains(&key),
                    uploaded: if report.uploaded.contains(&key) {
                        Some(now)
                    } else {
                        before.iter().find(|c| c.key == key).and_then(|c| c.uploaded)
                    },
                    note: String::new(),
                    key,
                })
                .collect();
        }
        Err(ApiError::Unauthorized) => status.linked_to = None,
        Err(ApiError::Network(_)) => status.offline = true,
        Err(e) => status.problems = vec![e.to_string()],
    }
}

/// Rewrites the words that depend on the clock: the tray line and each
/// character's note. Runs after every change and every half minute.
pub fn refresh(status: &mut Status, now: u64) {
    for c in &mut status.characters {
        c.note = if c.update_addon {
            "Update the addon on this PC to get the newest journey".into()
        } else if !c.here {
            "Only on your other PCs so far".into()
        } else if let Some(t) = c.uploaded {
            format!("Backed up {}", ago(now.saturating_sub(t)))
        } else {
            "Up to date".into()
        };
    }
    status.line = if status.linked_to.is_none() {
        "Not linked".into()
    } else if status.paused {
        "Syncing paused".into()
    } else if status.games.is_empty() {
        "WoW not found".into()
    } else if status.characters.iter().any(|c| c.update_addon) {
        "Update the addon on this PC".into()
    } else if status.offline {
        "Can't reach the server, trying again".into()
    } else if let Some(t) = status.last_synced {
        format!("Synced {}", ago(now.saturating_sub(t)))
    } else {
        "Syncing…".into()
    };
}
```

```rust
//! Runs the sync engine on a thread of its own and keeps the status the
//! tray and window show. Linking, pausing, adding a game folder and
//! unlinking stop the thread, change the saved state, and start it again.

use std::fs;
use std::path::{Path, PathBuf};
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, Mutex};
use std::thread::JoinHandle;
use std::time::{SystemTime, UNIX_EPOCH};

use rts_sync::api::{ApiError, Client, LinkResponse};
use rts_sync::installs::{self, GameFolder};
use rts_sync::state::{State, Tokens};
use rts_sync::sync::{self, Report};
use rts_sync::watch;

use crate::status::{Character, Game, Status, apply, refresh};

pub fn now() -> u64 {
    SystemTime::now().duration_since(UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0)
}

/// Holds the status and tells the tray and window each time it changes.
#[derive(Clone)]
pub struct Notifier {
    status: Arc<Mutex<Status>>,
    on_change: Arc<dyn Fn(&Status) + Send + Sync>,
}

impl Notifier {
    pub fn new(on_change: impl Fn(&Status) + Send + Sync + 'static) -> Notifier {
        Notifier {
            status: Arc::default(),
            on_change: Arc::new(on_change),
        }
    }

    pub fn get(&self) -> Status {
        self.status.lock().unwrap().clone()
    }

    /// Changes the status, rewrites its clock-dependent words, and passes it on.
    pub fn update(&self, change: impl FnOnce(&mut Status)) {
        let mut status = self.status.lock().unwrap();
        change(&mut status);
        refresh(&mut status, now());
        (self.on_change)(&status);
    }
}

pub type Find = Arc<dyn Fn(&State) -> Vec<GameFolder> + Send + Sync>;

pub struct Runner {
    server: String,
    state_path: PathBuf,
    cache: PathBuf,
    tokens: Arc<dyn Tokens + Send + Sync>,
    find: Find,
    notifier: Notifier,
    stop: Arc<AtomicBool>,
    thread: Option<JoinHandle<()>>,
}

impl Runner {
    pub fn new(server: &str, data: &Path, tokens: Arc<dyn Tokens + Send + Sync>, find: Find, notifier: Notifier) -> Runner {
        Runner {
            server: server.to_string(),
            state_path: data.join("state.json"),
            cache: data.join("journeys"),
            tokens,
            find,
            notifier,
            stop: Arc::default(),
            thread: None,
        }
    }

    pub fn is_running(&self) -> bool {
        self.thread.as_ref().is_some_and(|t| !t.is_finished())
    }

    /// Brings the status up to date, then syncs if this PC is linked and
    /// syncing isn't paused.
    pub fn start(&mut self) -> Result<(), String> {
        self.stop();
        let state = State::load(&self.state_path).map_err(|e| e.to_string())?;
        let games = (self.find)(&state);
        let token = self.tokens.get();
        let local = local_keys(&games);
        let mut paused = false;
        self.notifier.update(|s| {
            s.linked_to = token.as_ref().and(state.battletag.clone());
            s.games = games
                .iter()
                .map(|g| Game {
                    path: g.path.display().to_string(),
                    name: g.name.clone(),
                    addon: installs::addon_version(&g.path),
                })
                .collect();
            for key in &local {
                if !s.characters.iter().any(|c| &c.key == key) {
                    s.characters.push(Character {
                        key: key.clone(),
                        here: true,
                        update_addon: false,
                        uploaded: None,
                        note: String::new(),
                    });
                }
            }
            s.characters.sort_by(|a, b| a.key.cmp(&b.key));
            paused = s.paused;
        });
        if token.is_none() || state.pc.is_none() || paused || games.is_empty() {
            return Ok(());
        }

        let stop = Arc::new(AtomicBool::new(false));
        self.stop = stop.clone();
        let (server, state_path, cache, notifier) = (self.server.clone(), self.state_path.clone(), self.cache.clone(), self.notifier.clone());
        self.thread = Some(std::thread::spawn(move || {
            let client = Client::new(&server, token);
            let mut state = state;
            let report = |result: &Result<Report, ApiError>| {
                let local = local_keys(&games);
                notifier.update(|s| apply(s, result, &local, now()));
            };
            if let Err(e) = watch::run(&client, &mut state, &state_path, &cache, &games, &stop, report) {
                notifier.update(|s| s.problems = vec![format!("Couldn't watch the game folders: {e}")]);
            }
        }));
        Ok(())
    }

    pub fn stop(&mut self) {
        self.stop.store(true, Ordering::Relaxed);
        if let Some(thread) = self.thread.take() {
            let _ = thread.join();
        }
    }

    /// After the player approves on the link page: keep the new token,
    /// forget what was uploaded under any old link, and start again.
    pub fn linked(&mut self, linked: LinkResponse) -> Result<(), String> {
        self.stop();
        self.tokens.set(&linked.token)?;
        let mut state = State::load(&self.state_path).map_err(|e| e.to_string())?;
        state.pc = Some(linked.pc);
        state.battletag = Some(linked.battletag);
        state.uploaded.clear();
        // Another link's version ids mean other journeys.
        let _ = fs::remove_dir_all(&self.cache);
        state.save(&self.state_path).map_err(|e| e.to_string())?;
        self.notifier.update(|s| {
            s.link_code = None;
            s.problems.clear();
        });
        self.start()
    }

    pub fn unlink(&mut self) -> Result<(), String> {
        self.stop();
        self.tokens.clear()?;
        let _ = fs::remove_dir_all(&self.cache);
        let state = State::load(&self.state_path).map_err(|e| e.to_string())?;
        State {
            picked: state.picked,
            ..State::default()
        }
        .save(&self.state_path)
        .map_err(|e| e.to_string())?;
        self.notifier.update(|s| {
            s.characters.clear();
            s.last_synced = None;
            s.problems.clear();
        });
        self.start()
    }

    pub fn add_folder(&mut self, path: PathBuf) -> Result<(), String> {
        self.stop();
        let mut state = State::load(&self.state_path).map_err(|e| e.to_string())?;
        if !state.picked.contains(&path) {
            state.picked.push(path.clone());
            state.save(&self.state_path).map_err(|e| e.to_string())?;
        }
        let found = !installs::game_folders(&path).is_empty();
        self.start()?;
        if !found {
            self.notifier.update(|s| {
                s.problems = vec![format!(
                    "No WoW game folder with Road to Sixty in {}. Pick the World of Warcraft folder itself.",
                    path.display()
                )]
            });
        }
        Ok(())
    }

    pub fn set_paused(&mut self, paused: bool) -> Result<(), String> {
        self.stop();
        self.notifier.update(|s| s.paused = paused);
        self.start()
    }
}

/// `Name-Realm` of every character with a saved file in these game folders.
pub fn local_keys(games: &[GameFolder]) -> Vec<String> {
    games
        .iter()
        .flat_map(installs::saved_files)
        .filter_map(|f| fs::read(&f.path).ok().as_deref().and_then(sync::roster_key))
        .map(|(name, realm)| format!("{name}-{realm}"))
        .collect()
}
```

```rust
//! thread runs on a thread of its own, so the window never waits on an
//! upload; it hears the outcome through the "status" event.

use std::path::PathBuf;
use std::sync::Mutex;

use rts_sync::api::Client;

use tauri_plugin_opener::OpenerExt;

use crate::runner::{Notifier, Runner};

#[tauri::command]
pub fn status(notifier: State<'_, Notifier>) -> Status {

#[tauri::command]
pub fn link(app: AppHandle) {
    std::thread::spawn(move || {
        let notifier = app.state::<Notifier>().inner().clone();
        let name = sysinfo::System::host_name().unwrap_or_else(|| "This PC".into());
        let result = rts_sync::link::link(
            &Client::new(crate::SERVER, None),
            &name,
            |url, code| {
                notifier.update(|s| s.link_code = Some(code.to_string()));
                let _ = app.opener().open_url(url, None::<&str>);
            },
            std::thread::sleep,
        );
        match result {
            Ok(linked) => with_runner(app.clone(), move |r| r.linked(linked)),
            Err(e) => notifier.update(|s| {
                s.link_code = None;
                s.problems = vec![format!("Linking didn't finish: {e}")];
            }),
        }
    });
}

}

#[tauri::command]

}

/// Runs a change to the runner on its own thread; a failure shows in the window.
pub fn with_runner(app: AppHandle, job: impl FnOnce(&mut Runner) -> Result<(), String> + Send + 'static) {
    std::thread::spawn(move || {
        let runner = app.state::<Mutex<Runner>>();
        let result = job(&mut runner.lock().unwrap());
        if let Err(e) = result {
            app.state::<Notifier>().update(|s| s.problems = vec![e]);
        }
    });
}
```

```rust
//! The Road to Sixty app (#1): the sync engine with a menu bar or tray icon
//! and a small window for setup and status. Started at login with
//! --hidden, it stays out of sight until the player opens it.

mod commands;
mod runner;
mod status;
mod tray;

use std::sync::{Arc, Mutex};
use std::time::Duration;

use rts_sync::state::{Keychain, data_dir};
use tauri::{Emitter, Manager, RunEvent, WindowEvent};

use runner::{Notifier, Runner};

/// The server this build talks to, set at build time for player builds.
pub const SERVER: &str = match option_env!("RTS_SERVER") {
    Some(server) => server,
    None => rts_sync::api::TEST_SERVER,
};

fn main() {
    tauri::Builder::default()
        // Must come first: a second copy only shows this one's window.
        .plugin(tauri_plugin_single_instance::init(|app, _, _| tray::show_window(app)))
        .plugin(tauri_plugin_dialog::init())
        .plugin(tauri_plugin_opener::init())
        .setup(|app| {
            #[cfg(target_os = "macos")]
            app.set_activation_policy(tauri::ActivationPolicy::Accessory);

            let tray = tray::build(app.handle())?;
            let handle = app.handle().clone();
            let notifier = Notifier::new(move |status| {
                tray.show(status);
                let _ = handle.emit("status", status);
            });
            let mut runner = Runner::new(
                SERVER,
                &data_dir(),
                Arc::new(Keychain),
                Arc::new(rts_sync::sync::games),
                notifier.clone(),
            );
            runner.start()?;
            app.manage(notifier.clone());
            app.manage(Mutex::new(runner));

            // "Synced 2 min ago" has to keep counting between passes.
            std::thread::spawn(move || {
                loop {
                    std::thread::sleep(Duration::from_secs(30));
                    notifier.update(|_| {});
                }
            });

            if !std::env::args().any(|a| a == "--hidden") {
                tray::show_window(app.handle());
            }
            Ok(())
        })
        .on_window_event(|window, event| {
            // Closing the window only hides it; syncing goes on.
            if let WindowEvent::CloseRequested { api, .. } = event {
                api.prevent_close();
                let _ = window.hide();
            }
        })
        .invoke_handler(tauri::generate_handler![
            commands::status,
            commands::link,
            commands::add_folder,
            commands::set_paused,
            commands::unlink,
        ])
        .build(tauri::generate_context!())
        .expect("the app failed to start")
        .run(|_, event| {
            // Only Quit in the tray menu ends the app (it passes an exit code).
            if let RunEvent::ExitRequested { code: None, api, .. } = event {
                api.prevent_exit();
            }
        });
}
```

```rust
//! Updates from the app's public releases. The tray offers one when a
//! check finds it, and the window's Account tab can check by hand.

use tauri::AppHandle;
use tauri_plugin_updater::UpdaterExt;

/// The newer version on offer, if any.
pub async fn check(app: &AppHandle) -> Result<Option<String>, String> {
    let update = app.updater().map_err(|e| e.to_string())?.check().await.map_err(|e| e.to_string())?;
    Ok(update.map(|u| u.version))
}

/// Downloads and installs the newer version, then restarts into it.
pub async fn install(app: &AppHandle) -> Result<(), String> {
    let Some(update) = app.updater().map_err(|e| e.to_string())?.check().await.map_err(|e| e.to_string())? else {
        return Ok(());
    };
    update.download_and_install(|_, _| {}, || {}).await.map_err(|e| e.to_string())?;
    app.restart();
}

#[tauri::command]
pub async fn check_update(app: AppHandle) -> Result<Option<String>, String> {
    check(&app).await
}

#[tauri::command]
pub async fn install_update(app: AppHandle) -> Result<(), String> {
    install(&app).await
}
```

```ts
// The updater's latest.json for one release, in Tauri's format: every
// platform needs a url and the text of its .sig file. The updater has no
// universal Mac entry, so both Mac processors point at the universal build.
//
//   bun scripts/latest-json.ts <version> <base url> <folder with the builds>

export type Built = { file: string; signature: string };

export function latestJson(o: { version: string; base: string; pubDate: string; mac: Built; windows: Built }) {
  const at = (b: Built) => ({ url: `${o.base}/app/${o.version}/${b.file}`, signature: b.signature });
  return {
    version: o.version,
    notes: `Road to Sixty ${o.version}`,
    pub_date: o.pubDate,
    platforms: { "darwin-aarch64": at(o.mac), "darwin-x86_64": at(o.mac), "windows-x86_64": at(o.windows) },
  };
}

if (import.meta.main) {
  const [version, base, folder] = Bun.argv.slice(2);
  if (!version || !base || !folder) throw new Error("usage: latest-json.ts <version> <base url> <folder>");
  const built = async (file: string) => ({ file, signature: (await Bun.file(`${folder}/${file}.sig`).text()).trim() });
  const json = latestJson({
    version,
    base,
    pubDate: new Date().toISOString(),
    mac: await built("Road-to-Sixty.app.tar.gz"),
    windows: await built(`Road-to-Sixty_${version}_x64-setup.exe`),
  });
  console.log(JSON.stringify(json, null, 2));
}
```
